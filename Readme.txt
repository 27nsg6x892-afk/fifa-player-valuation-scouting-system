# FIFA Player Valuation & Scouting System

## Overview
This project is a machine learning system for football player scouting. It predicts player market value and classifies player performance tier using player attributes.

## Dataset
The dataset contains 19,667 football players and 9 columns, including player information, numerical attributes, and market value.

## Objectives
- Predict player market value
- Classify player performance tier
- Compare multiple machine learning models
- Build a final scouting system for new player profiles

## Methods Used
- Data preprocessing
- Feature engineering
- One-hot encoding
- Scaling
- Cross-validation
- Regression models
- Classification models
- Ensemble learning

## Models Used
- Lasso Regression
- Ridge Regression
- KNN
- SVM
- Random Forest
- Voting Regressor
- Voting Classifier

## Results
- Final regression model: Voting Regressor Ensemble
- Test R²: 0.9757
- Final classification model: SVM Classifier
- Test accuracy: 86.17%
